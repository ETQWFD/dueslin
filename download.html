DUESLIN 1.0 最终稳定版说明

  • root 默认密码：1234（登录后可用 passwd 修改）
  • duiver 命令：在终端输入 duiver 弹出版本信息窗口（版本 / 开发者 etc / 联系方式 / 官网），无图形环境时自动输出文本版
  • 图形安装：语言 → 许可协议 → 磁盘选择/分区 → 复制文件 → 5 秒重启 → 用户配置 → 进入桌面
  • 桌面版：C 语言自研轻量桌面（Win11 风格、海蓝背景 + D Logo、任务栏、开始菜单）+ Edge 浏览器 + 全新简化命令系统（install python 等），设置内可更换壁纸/动态背景
  • 服务器版：无桌面、纯终端，适合开发与部署，root 密码同样为 1234
  • 精简版：图形化安装 + 轻量桌面，适合测试与旧机器
