安装方式与 Windows 一致

四步完成安装

图形化安装界面（类苹果风格 UI），自动分区、自动解压 .wim 镜像、自动安装引导，完成后自动重启。

下载镜像

获取 DUESLIN ISO（小于 1GB），校验无误。

写入 U 盘

用 Rufus / Ventoy / dd 制作启动盘，BIOS 与 UEFI 均支持。

启动安装

从 U 盘启动，选择磁盘，系统自动完成分区与解压。

重启进入桌面

安装完成自动重启，配置用户与 WiFi 后即进入桌面。

开箱即用

面向旧设备，该有的都有

秒级启动

精简系统与轻量桌面，开机数秒即达桌面，老机械硬盘也能流畅运行。

极致轻量

安装仅需 400MB+ 磁盘，1GB 内存流畅运行，释放旧电脑的全部性能。

Windows 式桌面

底部任务栏、开始菜单、托盘、右键菜单，上手零成本。

全新命令系统

简化命令（install / files / wifi…），Linux 与 cmd 命令同样可直接使用。

PE 修复模式

输入 pe te=1 即可启用修复环境：修引导、查磁盘、重装系统。

驱动齐全

WiFi、蓝牙、音频、Intel / AMD 显卡驱动开箱即用，无需手动安装。
